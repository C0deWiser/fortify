# Password confirmation using passkey

When user accessing a page, that is protected with `password.confirm` 
middleware, they redirected to `resources/views/confirm-password.blade.php`

Here, JavaScript tries to invoke passkeys. If device has any, it allows user to 
use passkey. If device has no passkeys, user just provide their password.

The problem:

device has no stored passkeys. But user-agent (Safari 27) shows the popup 
with a message: У вас нет сохраненных ключей входа для этого сайта.

Can JavaScript detect passkey availability without rising such popup?

---

## Answer

Passkey availability cannot and should not be probed from JavaScript — the platform withholds
that information for fingerprinting reasons, and the capability APIs do not substitute for it.
The correct remedy is to render the passkey flow only when the authenticated user has a
passkey, which makes the reported popup unreachable rather than merely unlikely.
